# Simplify API Config Model

The API config storage model keeps only the minimal fields needed at runtime, and no longer stores legacy metadata such as a brand-name provider, `isDefault`, `createdAt`, or `updatedAt`. OpenAI, DeepSeek, and SiliconFlow in the UI are only presets used when creating a config; the runtime and storage layers recognize only the protocol family. The deletion rule is now "keep at least one config" rather than relying on a special default-config marker. API requests always go through the extension background, and `useBackgroundProxy` no longer exists as a user setting or runtime branch.
